Лабраторная работа по программированию на языке c++, реализующая систему классов
для моделирования случайных величин с дискретным набором состояний (Dice,
ThreeDicePool, PenaltyDice, BonusDice, DoubleDice) и проверяющая их статистические
свойства прямыми измерениями.

## Структура

- `cpp/main.cpp` — иерархия классов на основе полиморфизма подтипов
  (`RandomVariable` → `Dice`, `ThreeDicePool`, `PenaltyDice`, `BonusDice`,
  `DoubleDice`), запись мат. ожиданий и гистограмм вероятностей в `data/laba_4`.
- `python/analyze.py` — построение гистограмм и таблицы мат. ожиданий в `plots/laba_4`.
- `Probability-Lab.pdf` — условие лабораторной.

## Запуск

```
cd cpp
g++ -std=c++17 -O2 -Wall -o main main.cpp
./main
cd ../python
python analyze.py
```

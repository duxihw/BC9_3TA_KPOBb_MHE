# Лабораторная работа №5. Управление ресурсами

Задание находится в [Grid-Lab.pdf](Grid-Lab.pdf).

- `grid.hpp` — шаблон `Grid<T, N>`, размерность по умолчанию равна 2.
- `main.cpp` — небольшой пример работы.

Одномерная сетка владеет массивом элементов и реализует правило пяти.
Память выделяется через `std::allocator`, а объекты создаются отдельно.
Поэтому конструктор с заполнением работает и для типов без конструктора
по умолчанию. Если создание элементов завершится исключением, стандартные
функции `uninitialized_*` уничтожат уже созданные объекты, а `catch` освободит память.

Многомерная сетка хранит в `std::vector` сетки меньшей размерности.
Например, `Grid<int, 3>` состоит из двумерных сеток, а те — из строк.
`g[i]` возвращает ссылку на подсетку, а для константной сетки — её копию.
`g(i, j, k)` обращается к самому элементу. Индексы должны быть в пределах сетки.

Конструктор только с размерами вызывает конструкторы элементов по умолчанию.
Значения простых типов, например `int`, перед чтением нужно присвоить явно.
Конструктор с последним аргументом-значением сразу заполняет сетку его копиями.

Сборка и запуск из папки `laba_5` (GCC, C++17):

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o main.exe
.\main.exe
```

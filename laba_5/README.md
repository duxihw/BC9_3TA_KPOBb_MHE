# Лабораторная работа №5. Управление ресурсами

Задание находится в [Grid-Lab.pdf](Grid-Lab.pdf).
Весь код и пример использования находятся в `main.cpp`.

`Grid<T, N>` хранит обычный массив сеток `Grid<T, N - 1>`.
База рекурсии — специализация `Grid<T, 1>`, которая хранит массив элементов `T`.
Например, `Grid<int, 3>(2, 3, 4, 7)` создаёт две двумерные сетки,
каждая из которых содержит три строки по четыре элемента со значением 7.
По умолчанию N = 2, поэтому `Grid<float>` остаётся двумерной сеткой.

Первый размер конструктора задаёт число подсеток текущего уровня,
остальные аргументы передаются конструкторам подсеток. Оператор `()`
аналогично передаёт оставшиеся индексы следующему уровню.
`g[i]` возвращает ссылку на подсетку, а для константной сетки — её копию.
На последнем уровне возвращается сам элемент.

Память выделяется обычным `new[]` и освобождается через `delete[]`.
Каждый уровень реализует правило пяти. Копирование рекурсивно копирует
подсетки, а перемещение передаёт указатель без копирования элементов.
Присваивание значения рекурсивно заполняет всю сетку.

Индексы должны быть в пределах сетки. Элементы простых типов, созданные
конструктором только с размерами, перед чтением нужно заполнить.
Обработки исключений нет.

Сборка и запуск из папки `laba_5`:

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o main.exe
.\main.exe
```
